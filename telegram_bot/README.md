# 🤖 Telegram Order Intake Bot

Бот для автоматического приёма и брифинга заказов на разработку сайтов и Telegram-ботов.

---

## ⚡ Как быстро запустить бота:

### 1. Получите токен у @BotFather
1. Откройте **@BotFather** в Telegram.
2. Введите команду `/newbot`.
3. Укажите имя (например, `Dev Order Bot`) и юзернейм (например, `my_dev_order_bot`).
4. Скопируйте полученный **HTTP API Token**.

---

### 2. Узнайте ваш личный Chat ID
1. Откройте **@userinfobot** в Telegram.
2. Нажмите `/start` и скопируйте числовое значение **Id** (например, `123456789`).

---

### 3. Создайте файл `.env`
В папке `telegram_bot` создайте файл `.env` и вставьте данные:

```env
BOT_TOKEN=ВАШ_ТОКЕН_ОТ_BOTFATHER
ADMIN_CHAT_ID=ВАШ_CHAT_ID
PORT=8080
```

---

### 4. Запустите бота
```bash
# Перейдите в папку бота
cd d:\Portfolio\telegram_bot

# Установите зависимости
pip install -r requirements.txt

# Запустите бота
python main.py
```

После запуска бот станет мгновенно принимать заказы, проводить 5-шаговый брифинг клиентов и слать вам карточки с кнопкой **«💬 Написать клиенту»**!
